A make.fun entry for **The Self-Checkout Is Judging You**: one funny remark
from a judgmental self-checkout machine, at most 200 characters.

`main.ts` (Node 22) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

> You scanned the same avocado four times. I know. I counted. So did everyone behind you.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=output node main.ts
```
